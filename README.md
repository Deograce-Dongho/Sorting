# Sorting Algorithms

## Overview

This project explores the implementation of **sorting algorithms in C**.

The goal is to understand how different sorting approaches work and to practice algorithmic problem-solving, data manipulation, and performance considerations.

## Features

* Implementation of sorting algorithms
* Integer array manipulation
* Algorithm comparison
* Console-based execution
* Testing with different input data

## Technologies

* **C**
* Standard C Library
* GCC

## Concepts Practiced

* Sorting algorithms
* Arrays
* Functions
* Loops
* Algorithmic complexity
* Data manipulation
* Problem-solving

## How to Run

Clone the repository:

```bash
git clone https://github.com/Deograce-Dongho/Sorting.git
cd Sorting
```

Compile the project:

```bash
gcc -Wall -Wextra -o sorting *.c
```

Run it:

```bash
./sorting
```
